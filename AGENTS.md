# Project Rules

* Use FastAPI backend
* Use React frontend with Vite
* Use PostgreSQL
* Use service-based architecture
* Use modular structure
* Keep business logic out of routes
* Use async FastAPI routes where possible
* Use Pydantic schemas
* Use SQLAlchemy ORM
* Use Tailwind CSS
* Use reusable React components
* Use environment variables
* Use clean production-ready code
* Add docstrings
* Use JWT authentication
